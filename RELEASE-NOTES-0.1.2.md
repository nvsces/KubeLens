## KubeLens 0.1.2

Вход в облачные кластеры через плагины авторизации: DigitalOcean (в том числе SSO), GKE, EKS,
AKS, OIDC. Раньше окно кластера с такими контекстами показывало непонятную ошибку со ссылкой
на документацию Kubernetes, а вход через браузер обрывался на середине.

### Вход через плагины авторизации

Если токен для контекста выдаёт внешняя программа (`exec` в kubeconfig: `doctl`,
`gke-gcloud-auth-plugin`, `aws`, `kubelogin`…), KubeLens при открытии окна кластера запускает
её сам, один раз, и ждёт входа до 5 минут. Над таблицей появляется полоса состояния:

- **Идёт вход** — плагин открыл браузер; есть ссылка «Открыть страницу входа», если вкладку
  закрыли, и кнопка «Отмена»
- **Вход не удался** — текст ошибки плагина и кнопки «Войти» и «В Терминале». Повторно
  приложение само не входит, чтобы автообновление не открывало браузер снова и снова
- **Плагин не установлен** — команда установки и кнопка «Установить в Терминале»

Пока идёт вход, остальные запросы ждут его, а потом kubectl берёт токен из кэша плагина. Когда
срок токена истекает, вход повторяется. Та же полоса есть в карточке контекста, а кнопка
«Проверить связь» заодно повторяет вход.

Какой плагин поставить для своего облака — в README, раздел
[«Плагины авторизации»](https://github.com/nvsces/KubeLens#плагины-авторизации).

### Исправления

- В ошибках kubectl показывается суть («executable doctl not found», «connection refused»),
  а не последняя строка вывода — обычно это была ссылка на документацию
- При проблеме со входом алерт об ошибке больше не всплывает на каждое автообновление
- При переключении вида ресурса незавершённый запрос kubectl останавливается, а не досчитывается
  в фоне

### Установка

Скачайте `KubeLens-0.1.2.dmg` **браузером с этой страницы** и перетащите в «Программы».
Приложение подписано Developer ID и нотаризовано Apple — открывается обычным двойным
кликом, без предупреждений Gatekeeper.

Требуется macOS 14.4+ (Apple Silicon и Intel — универсальный бинарник).
Для окна ресурсов кластера нужен `kubectl` в PATH или путь к нему в настройках, а для облачных
кластеров — ещё и плагин авторизации (см. README).

Приложение без окна в Dock (`LSUIElement`) — только иконка в строке меню.
Окна открываются из её меню: «Открыть KubeLens…» (⌘O) и «Ресурсы кластера…» (⌘K).

Если DMG попал к вам через мессенджер, macOS может отказать в запуске — снимите атрибуты карантина:

```bash
xattr -cr /Applications/KubeLens.app
```
