## KubeLens 0.1.1

Обновлённый интерфейс окна кластера и выбор темы. Обязательное обновление для тех,
кто ставил 0.1.0: там при определённых настройках приложение не запускалось.

### Выбор темы

Настройки → «Оформление» или пункт «Тема» в строке меню: **Как в системе**, **Светлая**,
**Тёмная**. Применяется сразу ко всем открытым окнам, включая окна кластера,
и запоминается между запусками.

### Интерфейс окна кластера

- **Сайдбар** — количество объектов рядом с каждым видом ресурса, заголовки разделов
  капителью, иконка активного пункта акцентным цветом
- **Таблицы** — строки выше, чередование фона, статусы бейджами с цветной точкой,
  вторичные колонки приглушены, имя объекта — ссылка на его страницу
- **Страница объекта** — сводка и связанные объекты в карточках, выровненные колонки
  «ключ — значение», поля по краям, вкладки таблетками
- **Цвета состояний** — единая палитра: зелёный для Running и Active, оранжевый для
  Pending и Updating, красный для CrashLoopBackOff и Failed, серый для Scaled down

### Исправления

- Приложение падало при запуске (SIGTRAP), если тема применялась до создания
  главного окна приложения
- Логи и Describe занимают всё окно, текст прижат к левому краю, перенос длинных
  строк включён по умолчанию
- Контексты с одинаковым именем в разных файлах kubeconfig больше не сливаются
  в одну строку списка

### Установка

Скачайте `KubeLens-0.1.1.dmg` **браузером с этой страницы** и перетащите в «Программы».
Приложение подписано Developer ID и нотаризовано Apple — открывается обычным двойным
кликом, без предупреждений Gatekeeper.

Требуется macOS 14.4+ (Apple Silicon и Intel — универсальный бинарник).
Для окна ресурсов кластера нужен `kubectl` в PATH или путь к нему в настройках.

Приложение без окна в Dock (`LSUIElement`) — только иконка в строке меню.
Окна открываются из её меню: «Открыть KubeLens…» (⌘O) и «Ресурсы кластера…» (⌘K).

Если DMG попал к вам через мессенджер, macOS может отказать в запуске — снимите атрибуты карантина:

```bash
xattr -cr /Applications/KubeLens.app
```
