## KubeLens 0.1.0

Первый релиз. Kubernetes в строке меню macOS: kubeconfig под контролем и графический
обозреватель ресурсов кластера — от подов до ингрессов.

### Строка меню

- Имя текущего контекста рядом с иконкой, переключение контекста в один клик
- Подменю Namespace с отметкой текущего
- **⌘K** — окно ресурсов кластера, **⌘O** — окно kubeconfig

### Kubeconfig

- Несколько файлов сразу: цепочка `$KUBECONFIG` (читается из логин-шелла) плюс добавленные вручную
- Редактор кластера (адрес, CA встроенный или файлом, `insecure-skip-tls-verify`, `proxy-url`)
  и пользователя (токен, сертификат, логин/пароль, exec-плагин, auth-provider, impersonate)
- Переименование кластеров и пользователей с обновлением ссылок из контекстов
- Импорт другого файла со слиянием, экспорт контекста в отдельный файл (`--flatten`)
- Контекст из файла вне `$KUBECONFIG` при выборе копируется в основной файл, чтобы kubectl его увидел
- Перед каждой записью — копия файла в `~/Library/Application Support/KubeLens/backups/`,
  запись атомарная с правами `0600`; правки снаружи подхватываются сразу

### Ресурсы кластера

Поды, деплойменты, StatefulSet, DaemonSet, ReplicaSet, Jobs, CronJobs, HPA, сервисы,
ингрессы, endpoints, NetworkPolicies, ConfigMaps, Secrets, ServiceAccounts, квоты,
PVC, PV, StorageClasses, RBAC, ноды, namespaces, события, CRD.

- Таблицы с колонками как у `kubectl get`, фильтр, выбор namespace, автообновление
- Страница объекта в стиле Rancher: состояние, сводка, карточки Поды / Ресурсы / Insights,
  вкладки со счётчиками; у нагрузки первой открывается таблица её подов
- Логи с потоковым выводом, выбором контейнера, фильтром и подсветкой уровней
- Shell в контейнере через Terminal.app, port-forward, describe, события
- Правка без YAML: образ, imagePullPolicy, переменные окружения, requests/limits, реплики
- Редактор ConfigMap и Secret по ключам, у секретов — расшифровка по переключателю
- «Кто использует» у ConfigMap и Secret: нагрузки, которые на них ссылаются, с кнопкой Redeploy
- Редактируемый YAML любого объекта и создание объектов из YAML с шаблонами

### Как устроено

Внешних зависимостей нет: YAML разбирает собственный парсер, порядок ключей и неизвестные
поля при записи сохраняются. Обмен с кластером идёт через `kubectl`, поэтому работают все
способы аутентификации из kubeconfig — exec-плагины облаков, OIDC, сертификаты.
Без `kubectl` доступна вся работа с файлами kubeconfig.

### Установка

Скачайте `KubeLens-0.1.0.dmg` **браузером с этой страницы** и перетащите в «Программы».
Приложение подписано Developer ID и нотаризовано Apple — открывается обычным двойным
кликом, без предупреждений Gatekeeper.

Требуется macOS 14.4+ (Apple Silicon и Intel — универсальный бинарник).
Для окна ресурсов кластера нужен `kubectl` в PATH или путь к нему в настройках.

Приложение без окна в Dock (`LSUIElement`) — только иконка в строке меню.
Автозапуск включается в настройках: «Запускать при входе в систему».

Если DMG попал к вам через мессенджер, macOS может отказать в запуске — снимите атрибуты карантина:

```bash
xattr -cr /Applications/KubeLens.app
```
